Reference

Attendly API

Every endpoint the frontend calls, grouped by area. Each entry lists the exact path, who's allowed to call it, what to send, and what comes back — so you can build against it without reading the controller source.

Base URL & auth

All routes are prefixed with /api, e.g. http://localhost:5000/api/auth/login.

Every route except POST /auth/login and GET /health requires a JWT, sent as:

Authorization: Bearer <token>

Get a token from POST /auth/login. Tokens expire after JWT_EXPIRES_IN (default 7 days).

Public Admin only Teacher (+ admin) Student only

Standard error shape

Errors always return JSON with at least a message field:

{ "message": "Human-readable explanation of what went wrong" }

Common status codes used throughout: 400 bad input, 401 missing/invalid token, 403 not allowed (wrong role, wrong class, outside geofence), 404 not found, 409 conflict (duplicate), 410 gone/expired (QR token, session).

Login and session management. There is no public registration endpoint — every account is created by an admin.

Log in with email + password and receive a JWT.Use case: the login screen for all three roles.

Attendance (QR sessions)

5 endpoints

The core mechanic. A teacher opens a 10-minute session; the QR image inside it rotates roughly every 40 seconds. Students scan it, the backend checks their GPS accuracy and distance from the classroom (Haversine formula, default 50m), and records attendance if everything checks out.

POST/attendance/sessionsTeacher / Admin

Opens a new live attendance session for a class and returns the first QR code.Use case: teacher taps "Start attendance" on a class card.

Request body
FieldTypeRequiredNotes
classIdObjectIdRequiredMust be a class assigned to this teacher
useMyCurrentLocationbooleanOptionalIf true, geofence uses lat/lng below instead of the class's stored location
latnumberOptionalRequired if useMyCurrentLocation is true
lngnumberOptionalRequired if useMyCurrentLocation is true
Success response

201

{
  "session": { "_id": "6660...", "class": "665f...", "sessionDate": "2026-07-20T09:00:00.000Z", "expiresAt": "2026-07-20T09:10:00.000Z" },
  "qr": { "dataUrl": "data:image/png;base64,iVBORw0KG...", "scanUrl": "https://app.attendly.com/attend/eyJhbGci...", "tokenExpiresAt": "2026-07-20T09:00:40.000Z" }
}
Possible errors
403 You are not assigned to this class
409 A live session already exists for this class
GET/attendance/sessions/:id/qrTeacher / Admin

Rotates the QR token and returns a fresh code image. The frontend polls this roughly every 30 seconds while a session is live.Use case: keeping the QR on the classroom screen fresh so a screenshot shared elsewhere goes stale fast.

Success response

200

{
  "qr": { "dataUrl": "data:image/png;base64,...", "scanUrl": "https://app.attendly.com/attend/eyJhbGci...", "tokenExpiresAt": "2026-07-20T09:01:20.000Z" },
  "sessionExpiresAt": "2026-07-20T09:10:00.000Z"
}
Possible errors
410 Session has expired or been closed
PATCH/attendance/sessions/:id/closeTeacher / Admin

Manually ends a session before its 10-minute window naturally expires.Use case: "Close session early" button once everyone present has scanned.

Success response

200

{ "message": "Session closed" }

Success response

200

{
  "session": { "_id": "6660...", "isLive": true, "expiresAt": "2026-07-20T09:10:00.000Z" },
  "totalStudents": 32,
  "presentCount": 27,
  "records": [ { "_id": "665f...", "student": { "name": "Priya Sharma", "studentId": "STU-014" }, "markedAt": "2026-07-20T09:02:14.000Z" } ]

POST/attendance/scanStudent only

Marks the logged-in student present for a session — the actual "scan" action. Rate-limited per IP as an anti-proxy measure.Use case: called automatically the moment a student's phone opens the /attend/:token link from the QR, after the browser reports their GPS location.

Request body
FieldTypeRequiredNotes
tokenstringRequiredThe rotating token from the QR/scanned link
latnumberRequiredFrom navigator.geolocation
lngnumberRequired
accuracynumber (meters)Optional but recommendedRejected if worse than MAX_ALLOWED_GPS_ACCURACY_METERS (default 100m)
Example request
{ "token": "eyJhbGciOiJIUzI1NiIs...", "lat": 30.9011, "lng": 75.8574, "accuracy": 12 }
Success response

201

{
  "message": "Attendance marked successfully",
  "record": {
    "_id": "665f...",
    "session": "6660...",
    "student": "665b...",
    "distanceMeters": 14,
    "status": "present",
    "markedAt": "2026-07-20T09:02:14.000Z"
  }
}
Possible errors
410 QR code has expired. Ask your teacher to refresh it.
403 You are not enrolled in this class
400 Location signal too weak/unreliable (accuracy 180m). Move to an open area and try again.
403 You are 82m from the classroom. Must be within 50m to mark attendance. (also returns distanceMeters + maxDistanceMeters)
409 Attendance already marked for this session
